# Расширение возможностей ГУ Haval M6

Скрипт для установки дополнительных приложений и функций на головное устройство (ГУ) автомобиля Haval M6.

- **Группа в Telegram**: https://t.me/haval_m6p
- **Автор оригинального скрипта**: Александр (тг: @dahelmm)
- **Конвертация в bash**: Anton (https://github.com/Anton111111, тг: @TheManFromSaturn)

## ⚠️ Важное предупреждение

**Автор скрипта не несет ответственности за выход из строя головного устройства. Все действия выполняются на ваш страх и риск.**

## 📋 Описание

Данный скрипт позволяет устанавливать и управлять дополнительными приложениями на головном устройстве Haval M6, включая:

- **Android Auto** - для интеграции с Android устройствами
- **CarPlay** - для интеграции с iOS устройствами  
- **HUR** - дополнительные функции головного устройства
- **DuDu** - альтернативный интерфейс
- **Autokit** - инструменты автомобиля
- **NavBar** - настраиваемая навигационная панель
- **BackButton** - кнопка возврата

## 🛠️ Требования

### Программное обеспечение
- **ADB (Android Debug Bridge)** - должен быть установлен и доступен в PATH
- **Bash** - для выполнения скрипта

### Приложения
В папке `apps/` должны находиться следующие APK файлы:
- `Autokit.apk`
- `BackButton.apk` 
- `DuduAutoUi1.001008.apk`
- `HUR_7.2.1.apk`
- `nu_navbar-3_2_1.apk`

## 🚀 Установка и настройка

### 1. Подготовка головного устройства

1. Зайдите в настройки ГУ
2. Поочередно 6 раз нажмите: **"Дисплей"** → **"Громкость"** → **"Общие"**
3. Откроется окно ввода пароля
4. Подключите проводную USB клавиатуру или используйте Bluetooth-клавиатуру на телефоне
5. Введите пароль: `adayo2002`
6. **Перед нажатием "ОК" отключите клавиатуру**, затем нажмите "ОК"
7. В инженерном меню включите пункт **"ADB"**
8. Подключите USB кабель к порту на полке под ГУ

### 2. Запуск скрипта

```bash
chmod +x install.sh
./install.sh
```

## 📱 Функции скрипта

### Основные действия:

1. **Установить Android Auto** - полная установка Android Auto с необходимыми компонентами
2. **Установить Carplay** - установка поддержки Apple CarPlay
3. **Удаление установленных приложений** - безопасное удаление ранее установленных приложений
4. **Установить HUR** - установка только приложения HUR
5. **Запустить HUR** - быстрый запуск приложения HUR без перезагрузки ГУ
6. **Удалить HUR** - удаление приложения HUR
7. **Установить DuDu** - установка альтернативного интерфейса DuDu
8. **Удалить DuDu** - удаление интерфейса DuDu
9. **Посмотреть серийный номер ГУ** - отображение и сохранение серийного номера
10. **Забрать все APK с ГУ** - копирование системных и обычных APK на ноутбук
11. **Ручной ввод команды в консоли** - режим для продвинутых пользователей
12. **Выйти из скрипта**

При выборе пункта 10 APK сохраняются рядом со скриптом в отдельные каталоги:
- `backups/apk/system/` - APK из системных разделов
- `backups/apk/regular/` - APK из `/data/app`

### Автоматические проверки:
- Проверка подключения устройства через ADB
- Проверка наличия необходимых APK файлов
- Автоматическое получение root доступа
- Автоматическая перезагрузка ГУ после установки

## ⏱️ Анализ и диагностика скорости загрузки ГУ

В репозитории есть специальный скрипт для профилирования и поиска причин медленной загрузки ГУ:

```bash
chmod +x collect_diagnostics.sh
./collect_diagnostics.sh
```

### Возможности диагностики:
1. **Экспресс-диагностика без перезагрузки:**
   - Выгрузка таймингов `boot_progress_*` из журнала событий (сколько секунд заняло ядро, Zygote, сканирование APK менеджером пакетов, готовность экрана).
   - Сбор лога ядра `dmesg` (проблемы с монтированием eMMC, медленные драйверы).
   - Дамп полного `logcat`, запущенных процессов (`ps`) и служб автозапуска `BOOT_COMPLETED`.
   - Заполненность разделов памяти (`df -h`) и характеристики (`cpuinfo`, `meminfo`).
2. **Полное профилирование с перезагрузкой (Bootchart):**
   - Включение трассировки Android Bootchart на ГУ.
   - Контролируемая перезагрузка с точным замером секундомером до `sys.boot_completed`.
   - Выгрузка логов активности CPU, дискового ввода-вывода (I/O) и процессов.
   - Очистка системных триггеров Bootchart на ГУ после завершения.
3. **Автоматический сводный отчет:**
   - Таблица ключевых этапов старта прямо в терминале с цветовой подсветкой затянувшихся операций (>7 секунд подсвечиваются красным).
   - Сохранение изолированных сессий в папку `diagnostics/session_<ДАТА_ВРЕМЯ>/`.

Также поддерживаются флаги для быстрого запуска:
- `./collect_diagnostics.sh --quick` — экспресс-сбор текущих логов
- `./collect_diagnostics.sh --bootchart` — запуск профилирования старта с перезагрузкой
- `./collect_diagnostics.sh --analyze diagnostics/session_YYYY-MM-DD_HH-MM-SS` — повторный анализ сессии

## 🔧 Устранение неполадок

### Устройство не обнаружено
- Убедитесь, что ADB включен в инженерном меню ГУ
- Проверьте подключение USB кабеля
- Убедитесь что вы постучали в бубен и скрестили пальцы

### Ошибки при установке
- Убедитесь, что все APK файлы находятся в папке `apps/`
- Проверьте, что у вас есть права на запись в системную папку ГУ
- Попробуйте перезапустить скрипт

### ADB не найден
- Установите Android SDK или Android Studio
- Добавьте путь к ADB в переменную PATH
- На macOS можно установить через Homebrew: `brew install android-platform-tools`

### Проблемы с запуском HUR
- Убедитесь, что приложение HUR установлено на ГУ
- Проверьте правильность package name: `com.adayo.app.hurdisplay`
- Если приложение не запускается, попробуйте перезагрузить ГУ
- Используйте ручной режим для диагностики: `adb shell pm list packages | grep hur`
