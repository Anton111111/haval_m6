# Расширение возможностей ГУ Haval M6

Скрипт для установки дополнительных приложений и функций на головное устройство (ГУ) автомобиля Haval M6.

- **Группа в Telegram**: https://t.me/haval_m6p
- **Автор оригинального скрипта**: Александр (тг: @dahelmm)
- **Конвертация в bash**: Anton (https://github.com/Anton111111, тг: @TheManFromSaturn)

## ⚠️ Важное предупреждение

**Автор скрипта не несет ответственности за выход из строя головного устройства. Все действия выполняются на ваш страх и риск.**

## 📋 Описание

Данный скрипт позволяет устанавливать и управлять дополнительными приложениями на головном устройстве Haval M6, включая:

- **Android Auto** - для интеграции с Android устройствами
- **CarPlay** - для интеграции с iOS устройствами  
- **HUR** - дополнительные функции головного устройства
- **DuDu** - альтернативный интерфейс
- **Autokit** - инструменты автомобиля
- **NavBar** - настраиваемая навигационная панель
- **BackButton** - кнопка возврата

## 🛠️ Требования

### Программное обеспечение
- **ADB (Android Debug Bridge)** - должен быть установлен и доступен в PATH
- **Bash** - для выполнения скрипта

### Приложения
В папке `apps/` должны находиться следующие APK файлы:
- `Autokit.apk`
- `BackButton.apk` 
- `DuduAutoUi1.001008.apk`
- `HUR_7.2.1.apk`
- `nu_navbar-3_2_1.apk`

## 🚀 Установка и настройка

### 1. Подготовка головного устройства

1. Зайдите в настройки ГУ
2. Поочередно 6 раз нажмите: **"Дисплей"** → **"Громкость"** → **"Общие"**
3. Откроется окно ввода пароля
4. Подключите проводную USB клавиатуру или используйте Bluetooth-клавиатуру на телефоне
5. Введите пароль: `adayo2002`
6. **Перед нажатием "ОК" отключите клавиатуру**, затем нажмите "ОК"
7. В инженерном меню включите пункт **"ADB"**
8. Подключите USB кабель к порту на полке под ГУ

### 2. Запуск скрипта

```bash
chmod +x install.sh
./install.sh
```

## 📱 Функции скрипта

### Основные действия:

1. **Установить Android Auto** - полная установка Android Auto с необходимыми компонентами
2. **Установить Carplay** - установка поддержки Apple CarPlay
3. **Удаление установленных приложений** - безопасное удаление ранее установленных приложений
4. **Установить HUR** - установка только приложения HUR
5. **Удалить HUR** - удаление приложения HUR
6. **Установить DuDu** - установка альтернативного интерфейса DuDu
7. **Удалить DuDu** - удаление интерфейса DuDu
8. **Посмотреть серийный номер ГУ** - отображение и сохранение серийного номера
9. **Ручной ввод команды в консоли** - режим для продвинутых пользователей
10. **Выйти из скрипта**

## 🔧 Устранение неполадок

### Устройство не обнаружено
- Убедитесь, что ADB включен в инженерном меню ГУ
- Проверьте подключение USB кабеля
- Убедитесь что вы постучали в бубен и скрестили пальцы

### Ошибки при установке
- Убедитесь, что все APK файлы находятся в папке `apps/`
- Проверьте, что у вас есть права на запись в системную папку ГУ
- Попробуйте перезапустить скрипт

### ADB не найден
- Установите Android SDK или Android Studio
- Добавьте путь к ADB в переменную PATH
- На macOS можно установить через Homebrew: `brew install android-platform-tools`
